# Personal Portfolio Website

A modern and interactive portfolio website built with Next.js, React Bootstrap, and Three.js. This website showcases my projects, skills, and experience as a software engineer with a focus on machine learning.

## Features

-  Modern and responsive design
-  Interactive 3D elements using Three.js
-  Smooth animations and transitions
-  Project showcase section
-  Mobile-friendly layout
-  Dynamic content loading
-  Fast performance with Next.js

## Technologies Used

- **Frontend Framework**: Next.js
- **UI Components**: React Bootstrap
- **3D Graphics**: Three.js
- **Animations**: React Typed
- **Styling**: CSS/SCSS
- **Icons**: React Icons
